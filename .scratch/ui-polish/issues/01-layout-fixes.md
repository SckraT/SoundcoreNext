# 01 — Layout fixes

**Status:** done
**Blocked by:** —
**Implemented:** 2026-11-23

## Requirements

1. Breadcrumb in `PageHeading` (`desktop/ui/shell.slint`): center the chevron by
   layout (`cross-axis-alignment: center`), remove its manual `y`; keep TextLink
   and section text aligned.
2. Remove `AsidePanel` "Diagnostics" from Settings; no duplicate entry point.
3. Add a compact `Copy logs` action to the Diagnostics page (e.g. support row at
   the bottom) wired to `Actions.copy-logs()`.
4. Remove now-unused imports; verify no button overflows the Settings aside at
   280–380px and narrow window.
5. Tests/visual check at 100/125/150%; update UI_KIT/SOURCE if needed.

## Acceptance

- Arrow centered; Settings has no Diagnostics card; Copy logs works from
  Diagnostics; no overflow.

## Implementation (2026-11-23)

- `desktop/ui/shell.slint`: the `PageHeading` breadcrumb `HorizontalLayout` now
  uses `cross-axis-alignment: center`; the chevron `Icon` keeps its 12×12 size
  and loses the manual `y: (parent.height - self.height) / 2`. The device-name
  `TextLink`, the chevron and the section name are all centred by the layout, so
  they stay aligned at 100/125/150% instead of depending on a coordinate the
  managed layout also owns.
- `desktop/ui/pages/settings.slint`: the aside's `AsidePanel` "Diagnostics" card
  (Open diagnostics + Copy logs buttons) is removed, and the imports only it
  used (`Icon`, `PaletteChoice`) are removed with it. The aside keeps the
  Showcase, Home screen and About cards; the sidebar's Diagnostics navigation
  item is the only route to the page.
- `desktop/ui/pages/diagnostics.slint`: a compact `SupportActions` `Row` at the
  bottom of `DiagnosticsPage` contains one ghost `Copy logs` button
  (`Icons.copy`) wired to the existing `Actions.copy-logs()`. It renders on every
  step, so the action stays available after the Settings card is gone. The
  `@tr("Copy logs")` message is the same one the removed card used, so no
  translation document changed.
- `desktop/README.md` no longer places Copy logs on Settings; it records the
  Diagnostics support action and the single entry point. `SOURCE.md` records the
  vendored-tree changes.
- Preview: the Settings aside renders with 3 cards at every width; no button or
  text overflows the aside (335px at 1280×820, 380px at 1440×900, full width in
  the narrow branch). The Diagnostics captures show the Copy logs row at the
  foot of the page on the device, capture, review and done steps.
