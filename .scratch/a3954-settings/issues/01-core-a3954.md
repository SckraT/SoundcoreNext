# 01 — Core A3954 state and commands

**Status:** ready-for-agent
**Blocked by:** —

## Goal

Add A3954 parsing and write bodies to `core/crates/models` and
`core/crates/session`, without changing A3062/A3949 behavior.

## Requirements

1. Add `DeviceState.a3954: Option<A3954State>` or equivalent; every existing
   `DeviceState` constructor gets the field (`None` except A3954).
2. Parse the 165-byte A3954 `01 01` body from the reference parser:
   - base TWS fields 0..32 share the existing parser;
   - case firmware 32..37, case battery 37, case serial 38..44;
   - equalizer preset id 44..46, left/right 10 bands 46..56/56..66;
   - HearID block kept raw for writes;
   - buttons 116..124, ambient cycle 124, sound modes 125..129,
     case features 132..136, air pressure 136, low battery 140, LDAC 141,
     dual 142, auto power off 143..145, limit 145..148, spatial 148..151,
     easy chat 151..152/158, leak 153, case language 157, wearing 159,
     slide buttons 161..165.
   Validate the exact offsets against the reference on the committed capture.
3. A3954 sound-mode scale state and command builder (`06 81` 5-byte body).
4. A3954 equalizer: 22-preset catalog (common_settings_type_2), visible 8 bands,
   114-byte preset/custom body preserving HearID, model-aware API.
5. A3954 non-button setting commands: LDAC `01 FF`, dual `0B 84`/`0B 01`/writes,
   auto-off `01 86`, limit volume `20 82`/`20 81`, low battery `10 82`,
   cycle `06 82`, wearing `01 81`, leak `10 9A`, spatial `10 81`,
   easy chat `10 9D`, case language `07 8A` (if included).
6. Session methods for scale, A3954 EQ and A3954 setting writes; clear
   unsupported errors for others.
7. Tests: parse the committed real capture; every command body vector; A3062
   regression; no serial in debug/log output.

## Acceptance

- Core fmt/build/test/clippy green.
- A3954 state and commands covered by unit tests; A3062/A3949 tests unchanged.
- Report exact offsets/commands used and any deferred field.
